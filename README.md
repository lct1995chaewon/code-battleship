# 編程戰列艦 · Python 航海任務

瀏覽器內運作的 Python 學習遊戲，包含十個任務、3D 艦隊動畫及積木自由練習。

## GitHub Pages

在儲存庫 Settings → Pages 選擇 Deploy from a branch，使用 main 分支的 / (root)。
網站檔案須放於儲存庫根目錄，保留 .nojekyll 及所有 Pyodide 執行檔案。

學生不需要登入 ChatGPT。Python 透過本機附帶的 Pyodide 在瀏覽器執行。
進度僅保留於本次頁面，不會集中收集學生姓名或成績。

需透過 HTTP/HTTPS 網站開啟；不要直接雙擊 index.html。
